# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please email us privately instead of using the issue tracker.

**Do not open a public issue for security vulnerabilities.**

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt of your report within 48 hours and provide a status update within 7 days.

## Security Best Practices

We follow these security practices:
- Regular dependency updates
- Code review for all contributions
- Data encryption for sensitive information
- Input validation and sanitization
- OWASP security guidelines

## Supported Versions

| Version | Supported |
|---------|----------|
| 1.x     | ✅ Yes    |
| 0.x     | ❌ No     |

Thank you for helping keep our project secure!
